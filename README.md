# dangerous-object-classification
With rising concerns about safety in public spaces, there’s an urgent need to rethink how we detect threats, especially lethal ones like firearms. Most surveillance systems still depend on human operators watching endless camera feeds, which leaves too much room for error or delay. That’s where our project, Lethal Object Classification, comes in. We’re building a system that can automatically identify weapons using a small, affordable camera, the OpenMV RT1062, which can run in real time and doesn’t rely on bulky or expensive equipment. The idea is to create something practical and accessible, especially for places like schools, public transport, or crowded events, where fast detection can essentially save lives. For training and testing, we’re using the OD-WeaponDetection dataset [1], which includes labeled images of firearms in real-world settings. It provides us with a reliable foundation to develop a system that isn't only functional but also meaningful in the context of everyday public safety. 

The dataset used in this research consists of five separate image collections labeled as Database 1, Database 2, Database 3, Sohas_weapon, and Sohas_weapon-Test. Each database includes a variety of object categories such as pistols, knives, smartphones, bills, purses, and cards. The number of images ranges from 1,170 in the Sohas_weapon-Test set to 6,658 in Database 3. Across all datasets, images containing pistols and knives are consistently well-represented, while the number of images featuring smartphones, bills, purses, and cards is relatively lower. For the purpose of our study, we selected a subset of the data that includes 100 images containing knives, 100 images containing pistols, and 100 images that include visible human figures. This selection was made to ensure a focused and balanced representation of the target objects and human presence in the training material. 

For our custom training task, we selected 300 images from the weapon dataset, 100 images each from the pistol, knife, and regular human categories. This provided us with a controlled and balanced dataset for a three-class classification problem: lethal objects (pistols), lethal objects (knives), and non-lethal objects (humans). We divided this into 81% training and 19% testing to ensure a solid learning phase while keeping a fair portion for performance evaluation. Instead of going with object detection, which would have required manually drawing bounding boxes and dealing with labeling inconsistencies, we opted for classification. This approach saved time and allowed us to focus on getting reliable results quickly. To streamline the process even further, we used Edge Impulse’s feature that labels automatically based on file names. Each image was named according to its class, removing the need for manual intervention and minimizing potential errors during setup.
